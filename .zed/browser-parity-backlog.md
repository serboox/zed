# Встроенный браузер: бэклог паритета с Chrome и Firefox

Составлен 2026-10-20 по трём отчётам разведки и двум замерам. Движок: Servo 0.4.0
(`servo`, `servo-script`, `servo-layout`, `servo-net` 0.4.0, stylo 0.19, WebRender 0.69).
Эталон: документ `slack-preferences-spec.html` (587 КБ, 47 инлайновых SVG, 1379 классов
стиля) и документы из `.zed/`.

### Волна 1. Servo 0.4.0 -> 0.7.0 (отложена: пробный проход 2026-10-20 упёрся в конфликты зависимостей)

Пробный проход (изменения откатаны) показал цепочку конфликтов разрешителя Cargo, каждый из которых
решается только вендорингом и затрагивает ядро редактора, а не только браузер:

| Конфликт | Причина | Что потребуется |
|---|---|---|
| `freetype-sys` | `servo-fonts` и `harfbuzz-sys` 0.7/0.8 требуют ^0.23, а шрифтовой загрузчик окна (`zed-font-kit`) через `freetype` 0.7 привязан к ^0.20; пакет с `links = "freetype"` может быть один | Вендорить font-kit с `freetype` 0.8 и `freetype-sys` 0.23 (проверено по исходникам: API, которым пользуется font-kit, сохранился) |
| `cc` | `mozjs_sys` 153 требует `cc` >=1.3, а `tree-sitter-sequel` 0.3.2 держит `~1.0.90` | Вендорить грамматику SQL (15 МБ `parser.c`) с `cc = "1"` |
| `icu_calendar` | `mozjs_sys` 153 жёстко закрепляет `icu_capi =2.1.2` (`icu_calendar ~2.1.1`), а `boa_engine` 0.22 из `api_client` требует `~2.3.0` | Понизить `boa_engine` или вендорить его; затрагивает скрипты API-клиента |
| `libsqlite3-sys` | `servo-storage` 0.7 требует `rusqlite` 0.38 (`libsqlite3-sys` ^0.36), в workspace закреплён 0.35 для `sqlez` | Поднять до 0.36 (sqlx-sqlite 0.9 допускает <0.38) |
| `primeorder` | закрепление на rc можно снять | Удалить |

Вывод: переход возможен, но это отдельный этап с затронутыми `gpui` (шрифты), SQL-грамматикой и
API-клиентом. Он не исправляет ни SVG со стилями страницы, ни мигание, поэтому идёт после волн 2 и 3
и только с отдельным согласием.

| ID | Задача |

| W1.2 | Снять закрепление `primeorder = "=0.14.0-rc.14"`; `surfman` 0.14; набор функций `servo` без `default` (`baked-in-resources`, `clipboard`, `js_jit`, `multiprocess`, `webgl`, `webcrypto`, `brotli-compression-stream`) |

## Решения, нужные от Sergei (работа не останавливается)

1. `libsqlite3-sys` 0.36 затрагивает слой БД редактора (`sqlez`). Это обязательное условие перехода на 0.7.0.
2. Пробы W0.3 нужно запустить один раз на вашей машине; быстрый предварительный опыт: `ZED_HTML_PAGE_SHARING=0 zed-fast` и прокрутка того же документа, остаётся ли вспышка.
3. Не-Rust кода в плане нет: всё в Rust, внутри вендоренных `servo-script` и `html_render`.
